# f1-data-visualisations

these representations require the fastf1 api to be installed.

run py -m pip install fastf1 (on windows)

to install on windows:

1. install chocolately
2. run choco
3. choco install pip
   - you can also run py -m ensurepip --upgrade if pip isnt working but you know its downloaded
4. py -m pip install fastf1
